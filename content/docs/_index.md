**AI Development — Foundations** — the first course, and the place to start. Build from a raw
HTTP request up through sampling, tools, sandboxing, embeddings, RAG, and agents. Work through
the sections in order; each is self-contained, with a goal, runnable code, and a reference
implementation under `examples/`.

{{< unit-cards >}}

When you finish, continue with [Agent Memory](/agent-memory/), the follow-on course on
cross-session memory.
