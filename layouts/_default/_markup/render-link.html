{{- /* Link render hook. Lessons link to repo files with paths relative to the lesson's own directory, e.g. [common.py](../examples/common.py) or [README](../README.md). Those resolve correctly when reading the markdown in a clone or on GitHub, but would 404 on the built site. Here we rewrite any "../" link to the file's source on GitHub, leaving the source markdown untouched. Courses live at different depths, so "../" resolves to different repo paths: - Foundations lessons come from lessons/ (target content/docs/) - Agent Memory lessons come from agent-memory/lessons/ (target content/agent-memory/) - Context Compression lessons from context-compression/lessons/ (target content/context-compression/) - Feedback Loops lessons come from feedback-loops/lessons/ (target content/feedback-loops/) We resolve the link against the right source dir with path.Join (which cleans ".."). */ -}} {{- $dest := .Destination -}} {{- $external := or (hasPrefix $dest "http://") (hasPrefix $dest "https://") -}} {{- if and (not $external) (hasPrefix $dest "../") -}} {{- $srcdir := "lessons" -}} {{- with .Page.File -}} {{- if hasPrefix .Path "agent-memory/" -}}{{- $srcdir = "agent-memory/lessons" -}}{{- end -}} {{- if hasPrefix .Path "context-compression/" -}}{{- $srcdir = "context-compression/lessons" -}}{{- end -}} {{- if hasPrefix .Path "feedback-loops/" -}}{{- $srcdir = "feedback-loops/lessons" -}}{{- end -}} {{- end -}} {{- $repopath := path.Join $srcdir $dest -}} {{- $ghbase := printf "%s/blob/%s/" .Page.Site.Params.github_repo .Page.Site.Params.github_branch -}} {{- $dest = printf "%s%s" $ghbase $repopath -}} {{- $external = true -}} {{- end -}} {{ .Text | safeHTML }}
